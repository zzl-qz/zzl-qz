## Featured Projects

### [Rover-Suite](https://github.com/zzl-qz/Rover-Suite)

Lightweight microservice infrastructure that replaces manual upstream configuration with service discovery and gateway routing.

- Built-in registry, dynamic routing, and load balancing for mixed-language services.
- Runtime metrics and route visibility; Ops Agent investigates runtime issues and supports human-approved traffic changes with verification and rollback.
- `1.0.0-SNAPSHOT` single-node preview.

### [Pilot](https://github.com/zzl-qz/Pilot)

Self-contained coding agent built from scratch with native Java, without heavy framework bindings.

- Reads project structure to generate code and assist with code review, refactoring, and bug fixing.
- Designed to embed into custom developer platforms and IDE workflows.

### [XY Live](https://github.com/zzl-qz/xy-live)

Java microservices for live streaming and commerce, with a React + TypeScript demo client.

- Dubbo services, RocketMQ messaging, and Nacos discovery/configuration across business domains.
- Netty WebSocket/TCP IM gateway with ACK delivery, online routing, and offline messages.
- Includes JMeter reports for login, cache, and query performance.
